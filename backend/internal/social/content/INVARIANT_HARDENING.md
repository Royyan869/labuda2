# Social Content Invariant Hardening Archive

This file is a historical record of an older social-content hardening pass.
It is not current authority.

The semantics it described were superseded by the universal content contract:

- `fulfilled` / `request` lifecycle guidance is obsolete here.
- Top-level content kind authority is no longer documented in this file.
- Current enforcement lives in the content service, HTTP handlers, and the
  canonical repository / migration chain, not in this archive note.

If you are looking for the live contract, use the content domain source and the
active contract tests instead of this document.
